# 🛒 Shopzen

Shopzen is an online marketplace platform designed to make buying and selling simple, fast, and user-friendly.

---

## ✨ Features
- User authentication (signup/login)
- Product listing with categories
- Shopping cart and checkout flow
- Admin dashboard for product management
- Responsive design for mobile and desktop

---

## 🛠 Tech Stack
- **Frontend:** HTML, CSS, JavaScript (React recommended)
- **Backend:** Node.js + Express
- **Database:** MongoDB / PostgreSQL
- **Deployment:** Vercel / Netlify / Heroku

---

## 📦 Installation
```bash
# Clone the repository
git clone https://github.com/venkychichula/shopzen.git

# Navigate into the project
cd shopzen

# Install dependencies
npm install

# Run the development server
npm start
